# @dottedice/esign-audit-verifier

Offline signature verification engine, integrity checks, and Section 65B Indian Evidence Act compliant reference audit log compiler.

## Installation

```bash
npm install @dottedice/esign-audit-verifier pdf-lib
```

## Features
* **Integrity Validation**: Computes full SHA-256 digests and checks for tampering in downstream updates.
* **Section 65B Audit Logs**: Generates structured reference audit trail reports compliant with the evidentiary layout guidelines of Section 65B of the Indian Evidence Act / Bharatiya Sakshya Adhiniyam (BSA) 2023.
* **100% Offline**: Executes entirely on the local client without cloud data transit.

## Usage Example

```javascript
import { verifySignature } from '@dottedice/esign-audit-verifier';

// 1. Read signed PDF file bytes
const signedPdfBuffer = await fetch('/contracts/Signed_Contract.pdf').then(res => res.arrayBuffer());

// 2. Verify signature integrity and generate Audit logs
const verification = await verifySignature(new Uint8Array(signedPdfBuffer), {
  trustAuthority: 'My Custom CA' // Specify the trusted authority manually to override defaults
});

if (verification.isValid) {
  console.log('Document is Valid. Signed by:', verification.signer);
  console.log('Admissibility reference:', verification.auditCertificate.admissibilityReference);
} else {
  console.error('Tampering or modification detected!');
}
```

> [!IMPORTANT]
> The Section 65B Audit Certificate generated by this library is a structured reference log. In Indian courts, an electronic record is only admissible if accompanied by a physically signed Section 65B declaration from a competent officer in charge of the computer system. For a pre-formatted declaration builder, see `@dottedice/section-65b-certificate`.
